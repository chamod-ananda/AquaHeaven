# AquaHeaven

AquaHeaven is an informational website dedicated to aquarium plants. This website provides detailed insights into various aquatic plants, fostering a serene and educational experience for readers. The site is designed for optimal readability, with no additional functionalities beyond static content.

## Features

- Simple and clean design focused on content readability.
- Information about various aquarium plants, including their care and maintenance.
- Fully responsive layout for seamless viewing on desktops, tablets, and mobile devices.

## Technology Stack

- **HTML5**: Structuring the content.
- **CSS3**: Styling the website and ensuring a visually appealing layout.
- **JavaScript** (optional): For enhancing interactivity in the future if needed.

## Installation

1. Clone the repository:
   ```bash
   git clone <repository_url>
   ```
2. Open the project folder:
   ```bash
   cd aquaheaven
   ```
3. Open the `index.html` file in your browser to view the website.
